## Featured Projects

### AI Handwriting Assistant
![React](https://img.shields.io/badge/React-161b22?style=flat-square&logo=react&logoColor=61DAFB)
![TypeScript](https://img.shields.io/badge/TypeScript-161b22?style=flat-square&logo=typescript&logoColor=3178C6)
![Node.js](https://img.shields.io/badge/Node.js-161b22?style=flat-square&logo=nodedotjs&logoColor=339933)
![Express](https://img.shields.io/badge/Express-161b22?style=flat-square&logo=express&logoColor=white)
![OpenAI API](https://img.shields.io/badge/OpenAI_API-161b22?style=flat-square&logo=openai&logoColor=white)

**Problem:** Students and people who find handwriting difficult often struggle to produce neat written notes and answers.

**Solution:** A full-stack, AI-powered application where users type or dictate their answers, let AI organise and structure the content, review and edit the suggestions, and then convert the final text into handwriting-style notes that can be exported as PDF or PNG.

**My contribution:** application workflow design, frontend and backend implementation, AI integration and application logic, input validation, error handling and UX improvements.

> This is a learning and portfolio project. It is not presented as a production-ready product.

### Office Attendance Management System
![React](https://img.shields.io/badge/React-161b22?style=flat-square&logo=react&logoColor=61DAFB)
![Node.js](https://img.shields.io/badge/Node.js-161b22?style=flat-square&logo=nodedotjs&logoColor=339933)

### IoT-Enabled Consent-Based Location Tracking System
![ESP32](https://img.shields.io/badge/ESP32-161b22?style=flat-square&logo=espressif&logoColor=E7352C)
![MQTT](https://img.shields.io/badge/MQTT-161b22?style=flat-square&logo=mqtt&logoColor=660066)
![SQL](https://img.shields.io/badge/SQL-161b22?style=flat-square&logoColor=white)

**Problem:** Standard GPS is unreliable indoors, especially for working out which floor of a building someone is on, and location tracking should only happen with the user's consent.

**Solution:** An indoor floor-detection system that collects barometric sensor data on an ESP32, sends it over MQTT, and logs it to an SQL database, with tracking active only for users who have given consent.
